# AI 智能选号 · 微信小程序

基于多维数据分析的彩票号码生成小程序，支持双色球与大乐透，纯本地运行、零后端依赖。原生 WXML / WXSS / JavaScript 实现。

> 彩票每期开奖均为独立随机事件，历史数据与任何算法都无法预测未来结果。本项目仅供技术演示与娱乐，请理性购彩，未满 18 周岁禁止购彩。

## 功能

- **数据分析**：冷热号识别、遗漏排行、号码频率分布图、和值走势图，统计窗口 30 / 50 / 100 / 全部可切换，图表随窗口联动
- **智能生成**：智能平衡、追热、追冷、遗漏回补、纯随机五种策略，支持批量生成 1 / 5 / 10 注
- **约束过滤**：和值区间、奇偶比例、区间均衡、限制三连号
- **定胆 / 杀号**：锁定必含号码与排除号码，作为硬约束参与生成
- **手选号码**：点击选球、随机补全、一键收藏
- **收藏夹**：本地存储持久化，按彩种独立保存，支持批量检票
- **模拟开奖**：摇奖机式滚动定格动画，对比命中情况并按官方规则提示奖级
- **最新资讯**：公开最新开奖号码、销售额、奖池与一等奖注数，并汇总彩票新闻
- **战绩统计**：摇号次数、命中次数、命中率、最佳奖级，按彩种独立保存

## 本地调试

1. 打开微信开发者工具，选择「导入项目」
2. 目录选择本仓库根目录
3. AppID 选择测试号即可（`project.config.json` 中为 `touristappid`）
4. 编译预览，五个 tab 页均可离线运行

## 数据来源

| 彩种 | 来源 | 说明 |
|---|---|---|
| 双色球 | 中国福利彩票官方开奖接口 | 最近 500 期，含日期、销售额、奖池、一等奖注数 |
| 大乐透 | 500.com 历史开奖表 | 最近 500 期，含日期、销售额、一等奖注数与奖金 |

数据由同源的 Web / Android 项目每日定时抓取并同步，`utils/livedata.js`、`utils/data.js`、`utils/engine.js` 与 Web 版保持一致。抓取失败时保留上一份有效数据，小程序始终能渲染。

### 手动同步

```bash
# 从本地已 clone 的主仓库同步
python3 scripts/sync-from-app-repo.py --src ../ai-lottery/lottery-ai/js

# 或直接从 GitHub 拉取（无需本地主仓库）
python3 scripts/sync-from-app-repo.py
```

脚本会把 ES Module 语法改写为 CommonJS，并校验开奖数据完整性（期数、倒序、字段齐全），校验失败不会写入。

### 自动同步

`.github/workflows/sync-data.yml` 每日 22:50 UTC 拉取主仓库最新核心模块，运行测试后自动提交。也可在 Actions 页面手动触发。

### 测试

```bash
node scripts/test-miniprogram.js
```

使用 Node 模拟 `wx` API，覆盖五个页面的生命周期与主要交互（生成、定胆杀号、收藏、摇号、检票、复制），无需微信开发者工具即可验证逻辑。

## 核心算法

- **加权无放回抽样**：Efraimidis-Spirakis 指数键法，`key = -ln(U) / w`
- **智能平衡评分**：按和值偏离度、区间均匀度、奇偶比、连号长度、冷热搭配加权打分，从候选中择优
- **遗漏回补**：号码权重按当前遗漏相对理论平均遗漏（`pool/pick - 1`）的偏离呈高斯分布

## 与 Web / Android 版的差异

| 能力 | Web | 小程序 |
|---|---|---|
| 数据存储 | localStorage | `wx.setStorageSync` |
| 图表 | DOM Canvas 2D | 同层 Canvas 2D（`type="2d"`） |
| 外部链接 | 新标签页打开 | 复制链接并提示到浏览器打开 |
| 导航 | 自绘底部导航 | 原生 tabBar |
