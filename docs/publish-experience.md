# 发布体验版

体验版不需要经过类目审核，适合小范围验证。整个流程分三部分：微信后台准备（一次性）、本地配置、上传。

## 一、微信后台准备（一次性，约 5 分钟）

1. 注册小程序账号：https://mp.weixin.qq.com ，完成邮箱与主体信息验证
2. 拿到 **AppID**：后台「设置 - 基本设置」顶部，形如 `wx1234567890abcdef`
3. 生成 **代码上传密钥**：后台「开发 - 开发管理 - 开发设置」，找到「小程序代码上传」区域
   - 点击「生成」下载密钥文件（文件名形如 `private.wx1234567890abcdef.key`）
   - 同一区域把当前机器 IP 加入「IP 白名单」；不确定时可以先关闭白名单校验再试
4. 获取 **体验成员**：后台「管理 - 成员管理 - 体验成员」，添加要试用的微信号

## 二、本地配置

```bash
# 1. 把项目里的 AppID 换成真实值
#    编辑 project.config.json，将 "touristappid" 替换为你的 AppID

# 2. 安装上传工具
npm install -g miniprogram-ci

# 3. 密钥文件放到项目外，避免误提交（已在 .gitignore 排除 *.key）
mv ~/Downloads/private.wx1234567890abcdef.key ~/wx-upload.key
chmod 600 ~/wx-upload.key
```

## 三、上传

```bash
WX_APPID=wx1234567890abcdef \
WX_PRIVATE_KEY=~/wx-upload.key \
WX_VERSION=1.0.0 \
WX_DESC="首个体验版" \
node scripts/upload-ci.js
```

成功后会打印版本号与分包体积。

## 四、设为体验版

上传只是产生「开发版本」，还需要在后台转为体验版：

1. 打开 https://mp.weixin.qq.com 「管理 - 版本管理」
2. 在开发版本列表找到刚上传的版本，点击「选为体验版」
3. 系统生成体验版二维码
4. 「管理 - 成员管理 - 体验成员」添加试用者微信号（上限 90 人）

体验成员扫码即可使用，无需审核、无需备案。

## 备选方案：开发者工具上传

不想装 miniprogram-ci 时，也可以全程用图形界面：

1. 微信开发者工具打开本项目目录
2. 登录你的微信账号
3. 顶部「上传」按钮，填版本号与备注
4. 后续步骤同上（版本管理 -> 选为体验版）

## 常见问题

**上传报 IP 不在白名单**：后台关闭 IP 白名单，或把出口 IP 加进去。CI 环境出口 IP 会变，本地发布更省事。

**提示 AppID 与密钥不匹配**：密钥是绑定具体 AppID 生成的，换 AppID 要重新生成。

**体验版打开空白**：先用开发者工具在真机预览确认无误。本项目数据全部内置在 `utils/livedata.js`，不需要配置服务器域名。

**包体积超限**：主包上限 2MB。当前项目约 516KB，包含 276KB 数据，余量充足。
